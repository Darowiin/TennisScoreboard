# Tennis Scoreboard

Веб-приложение для ведения счёта теннисных матчей: запуск матча, пошаговый ввод очков по правилам тенниса и история завершённых матчей с поиском и пагинацией.

## Возможности

- **Новый матч** - укажите имена двух игроков; известные игроки подхватываются из БД, новые создаются автоматически.
- **Табло счёта** - очки (0 / 15 / 30 / 40), геймы, сеты; обработаны гейм-пойнт, «ровно»/«больше» (deuce/advantage) и тай-брейк при счёте 6:6 по геймам (до 7 очков с разницей в 2).
- **Матч до двух сетов** - при победе в 2 сетах матч автоматически завершается и сохраняется в БД.
- **Ссылка на матч** - каждому активному матчу выдаётся UUID: страницу табло можно обновлять и открывать заново (`/match-score?uuid=...`).
- **История матчей** - список завершённых матчей с постраничным выводом и фильтрацией по имени любого из игроков.

## Технологии

| Слой | Технология |
| --- | --- |
| Язык | Java 22 |
| Платформа | Jakarta Servlet 6.1 (Tomcat 11), упаковка WAR |
| ORM | Hibernate 7.0.0.Alpha2 (Jakarta Persistence) |
| БД | H2 2.3.232, in-memory |
| Веб-интерфейс | JSP + HTML/CSS |
| Утилиты | Lombok, Jackson |
| Тесты | JUnit Jupiter 6 |

Архитектура послойная: сервлеты-контроллеры (`com.controllers`) -> сервисы (`com.services`) -> DAO (`com.dao`, поверх Hibernate) -> JPA-сущности (`com.models`). Активные матчи живут в памяти (`ConcurrentHashMap` по UUID), завершённые - в БД.

> База данных - in-memory H2 (`jdbc:h2:mem:Scoreboard`, `create-drop`). После перезапуска сервера история матчей очищается.

## Запуск

Сборка:

```bash
mvn package
```

Готовый WAR появится в `target/`. Разверните его в Tomcat 11 (Jakarta EE 10):

```bash
cp target/TennisScoreboard-1.0-SNAPSHOT.war $CATALINA_HOME/webapps/
$CATALINA_HOME/bin/startup.sh
```

Приложение доступно по адресу `http://localhost:8080/TennisScoreboard/main`.

Запуск тестов (юнит-тесты логики счёта):

```bash
mvn test
```

## Структура страниц

| Маршрут | Описание |
| --- | --- |
| `/main` | Главная страница |
| `/new-match` | Форма создания матча |
| `/match-score?uuid=...` | Табло счёта активного матча, кнопки «Добавить очко» |
| `/matches?page=N&name=...` | Завершённые матчи: пагинация + фильтр по имени игрока |

## Структура проекта

```
src/main/java/com
├── controllers/   # сервлеты: /main, /new-match, /match-score, /matches
├── services/      # бизнес-логика: счёт, активные матчи, история
├── dao/           # доступ к данным через Hibernate
├── dto/           # объекты для передачи в представление
├── models/        # JPA-сущности: Player, Match
└── utils/         # Mapper, HibernateSessionFactoryUtil
src/main/webapp
├── WEB-INF/       # JSP-страницы и web.xml
└── css/           # стили
src/test/java      # юнит-тесты MatchScoreCalculationService
```
